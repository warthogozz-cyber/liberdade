# Documentação do Liberdade

Estes documentos formam o spec do MVP (v0.1 a v0.4). Comece pelo PRD.

| Documento | O que tem |
|---|---|
| [PRD](prd.md) | Visão, personas, critérios de sucesso, histórias com critérios de aceite, regras de cálculo com exemplos, conformidade e riscos |
| [Arquitetura](architecture.md) | Diagramas C4 (Mermaid), módulos, API v0.1, fluxos de login e offline, implantação, segurança e operação |
| [Modelo de dados](data-model.md) | Tabelas por versão, regras no banco e retenção (LGPD) |
| [Design system](design-system.md) | Tokens de cor com contraste verificado, tipografia, componentes, voz e tom, gamificação ética |
| [Wireframes](wireframes.md) | Fluxo principal do primeiro acesso ao primeiro gasto e telas das versões seguintes |
| [Roadmap](roadmap.md) | Fases, critérios de saída de cada versão, custos e payback |
| [ADRs](adr/README.md) | Decisões de arquitetura com alternativas e custos |

## Convenções

- Documentação de usuário e de produto em português do Brasil; código, commits e nomes técnicos em
  inglês.
- Valores em BRL. Todo preço, versão ou norma citado traz fonte e data da consulta e deve ser
  conferido de novo antes de virar decisão.
- Exemplos usam nomes e valores fictícios; nenhum dado pessoal real entra no repositório.
